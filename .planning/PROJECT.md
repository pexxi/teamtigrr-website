# TeamTigrr Landing Page

## What This Is

A landing page refresh for TeamTigrr, a junior sports duty management app. The page targets team leaders who make purchase decisions, with parents as influential secondary audience. The goal is to communicate clear benefits in a sporty, positive tone.

## Core Value

Team leaders can instantly see how TeamTigrr makes duty management effortless, fair, and private — and feel confident signing up their club.

## Context

**Current state:**
- Existing landing page at index.html uses Tailwind CSS
- Beta signup form already in place
- Current messaging feels "tacky and off-point" per user feedback
- Privacy not mentioned despite being a key differentiator

**Target audience insights:**
- Team leaders: Tired of maintaining Excel sheets, want easy solution
- Parents: Currently message volunteers one-by-one for swaps, creating unfair distribution
- Volunteers: Contact info currently exposed on public club web pages

**Pain points TeamTigrr solves (frame as benefits):**
1. Replaces cumbersome Excel sheets → Effortless scheduling
2. Eliminates one-by-one swap hunting → Fair, open swap requests to all
3. Removes public contact exposure → Volunteer privacy protected

## Constraints

- **Tech stack**: Static HTML with Tailwind CSS (CDN) — keep simple
- **Existing assets**: Current visual style (orange/dark theme, Teko/Inter fonts) can be refined but core brand maintained
