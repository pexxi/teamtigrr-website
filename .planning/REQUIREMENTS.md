# Requirements: TeamTigrr Landing Page

**Defined:** 2025-02-02
**Core Value:** Team leaders can instantly see how TeamTigrr makes duty management effortless, fair, and private.

## v1 Requirements

Requirements for landing page refresh. Each maps to roadmap phases.

### Copy & Messaging

- [x] **COPY-01**: Hero headline is benefit-focused and outcome-driven (not problem-focused)
- [x] **COPY-02**: All copy uses positive framing (lead with benefits, not pain points)
- [x] **COPY-03**: Privacy protection is elevated to prominent position (hero or near top)
- [x] **COPY-04**: Fair swap system messaging explains one request reaches all volunteers

### Content Sections

- [ ] **CONT-01**: FAQ section addresses 4-6 common objections (cost, setup time, privacy, switching)
- [ ] **CONT-02**: Social proof placeholder ready for testimonials ("Built by sports parents" or similar)
- [ ] **CONT-03**: "How It Works" 3-step visual process flow

### Performance

- [ ] **PERF-01**: Mobile-first responsive design verified across devices
- [ ] **PERF-02**: Page load time under 2.5 seconds (LCP metric)

## v2 Requirements

Deferred to future release. Tracked but not in current roadmap.

### Technical

- **TECH-01**: Migrate to Astro 5 + Tailwind v4 for 50-70% smaller bundles
- **TECH-02**: Replace Font Awesome CDN with tree-shakeable Lucide icons

### Content

- **CONT-04**: Video demo/explainer showing product in action
- **CONT-05**: Real customer testimonials with photos (requires beta users)
- **CONT-06**: Case study snippets with specific metrics (requires beta data)

### Advanced Features

- **ADV-01**: Interactive product demo (requires working product)
- **ADV-02**: ROI calculator for team leaders

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Backend functionality | This is landing page refresh only |
| Pricing page | Not part of this refresh, beta is free |
| Blog/content pages | Focus on main landing page conversion |
| Navigation menu changes | Current nav acceptable for homepage-style page |
| Multiple CTAs | Research shows single CTA converts better |
| Form field additions | Current 3 fields optimal, more fields hurt conversion |
